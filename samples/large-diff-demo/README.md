# 大容量差分デモ

約12,000行のテキストを使い、長いファイル内で差分の色・行記号・文字強調・接続線・スクロール同期が追えるか確認できます。各ファイルは約1MB未満で、アプリの読み込み上限内です。

- `A-large-baseline.txt`: 比較の基準
- `B-large-edited.txt`: Aから複数の値を変更し、行ブロックを追加・削除した版
- `C-large-third-version.txt`: Aから離れた位置に別の変更と追加を加えた版

## 開き方

3ファイルを同時にMacMergeへドロップするか、開始画面の「ファイルを開く」からまとめて選択します。Aを基準にBとCを比較できます。最初はB列の変更ナビゲーションを使い、次にC列へ切り替えてください。

このサンプルには途中の変更、行ブロックの追加・削除、末尾の追加を含めています。原本を保つため、保存を試す場合は先にファイルを複製してください。
