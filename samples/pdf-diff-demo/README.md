# PDF比較サンプル

`Invoice-A.pdf`と`Invoice-B.pdf`を同時にMacMergeへドロップするか、ファイル選択で両方を開いてください。日本語を含む2ページの請求書を使い、請求番号・宛先・金額・支払期限・口座番号・担当者名など、ページをまたいだ複数の文字差分を確認できます。

MacMergeはPDFのページ単位で抽出したテキストを比較画面に表示します。PDF自体の見た目、画像、レイアウトを比較する機能ではありません。PDFは読み取り専用です。

`Scanned-image-only.pdf`は文字データを含まず、ページ画像だけを含むサンプルです。読み込み時にスキャンPDFには未対応という案内が出ることを確認できます。
