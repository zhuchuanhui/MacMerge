# MacMerge 差分表示デモ

3ファイルをまとめて比較する場合は、`A-baseline.txt`、`B-edited.txt`、`C-third-version.txt`を同時にMacMergeへドロップするか、ファイル選択からまとめて開いてください。Aを基準にB列・C列それぞれの差分が表示されます。

2ファイルだけ試す場合は、AとBを選択してください。

## このサンプルで確認できる差分

- 同一行と変更行の見分け
- 行内の文字・数字の変更
- 行の追加（緑、`+`）と削除（赤、`−`）
- 複数行の追加・削除
- 行の並び替え
- 空行の追加と削除
- 日本語、記号、チェックマークなどの文字
- 折り返す長い行の部分変更
- 最終行の追加とファイル末尾

保存の動作も試す場合は、サンプルを複製してから編集してください。ここにあるファイルは比較用の原本です。
